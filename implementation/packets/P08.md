## Implemented behavior

- **Certainty preservation.** `submit` returns the union in A with E = never:
  local closed/stale capability and registration refusals become
  `not-submitted{ref, error}` (authentic ref always available — commands are
  WeakMap-registered capabilities; a forged object with no authentic entry is
  an `Effect.die` defect, never a forged receipt); completion-decode loss
  after dispatch becomes `outcome-unknown{ref, error}`; native arms decode
  one-to-one. Fiber interruption is NEVER rewritten into an arm: the callback
  bridge delivers nothing after interruption, signals native cancellation and
  joins the drain (`runtimeCancel` → `finalizeClose`, defect on incomplete).
- **Close policy.** Every owner (history/snapshot/command/cache) is scoped
  with an early `close()`/`release()` Effect returning `CloseReport`;
  finalizers rerun the same native transition and die with `CloseFailure` on
  incomplete/failed — a known receipt retained by the app survives a failed
  scope exit unchanged. Facades stop admission locally at close start;
  repeated close joins the native transition; borrows release only
  themselves (verified: no owner/cache close verbs dispatched on release).
- **Published reads.** Snapshot acquisition decodes provenance (identity,
  decision/state stamps, freshness) and wraps the returned core snapshot
  handle with P07's `internalPublishedReader`, so `get`/`execute`/`session`
  are literally the core capability — no log query dialect, result
  conversion, or writable escape exists.
- **Tenant borrows.** One native-backed typed cache; acquire returns a
  distinct scoped borrow whose release is one-shot and idempotent; stale
  borrows refuse `ClosedHandle` without dispatch; evict of a borrowed slot
  surfaces the native `SlotBorrowed` refusal; no TTL/renewal/timer/JS
  eviction/pre-lock cleanup — deleted, not rewrapped.
- **Admin certainty.** Mutating wrappers derive `OperationRef` (binding
  identity + caller OperationId) before dispatch; missing runtime service or
  registration refusal → `not-started`; lost completion → `outcome-unknown`;
  read-only status/verify have typed E. `completed(paused)` reports a frozen
  source honestly. `activateMigration`/`abortMigration` pass their bound
  refs verbatim; abort reports the durable target fence before source
  access. No admin journal, no manufactured maintenance receipts.
- **Input hygiene.** All caller data crossing outbound is checked (string
  bounds, positive counts, u64 bigints, scalar-only declared results,
  unshared Uint8Array); refusals surface as typed failures (or not-submitted
  pre-dispatch) before any native work. Wire values inbound are trusted
  typed-binding data, as in the core's runtime-native pattern.
