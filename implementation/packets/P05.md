## Implemented behavior (summary of what is real)

- One authoritative FS operation set; kernel exclusion acquired before
  cleanup, released last; paused holders keep ownership; hostile shapes
  refuse. S3 conditional grammar distinguishes known failure / known
  publication / unknown transport; emulator green is never claimed as S3
  qualification (the real lane is credential-gated and skips loudly).
- Streamed coherent checkpoints from ONE committed read snapshot; bounded
  validated suffix rebase progressing under writes (no quiet-window restart,
  no re-export per retry); epoch-moved chunks restaged; retirement rides the
  checkpoint; count+bytes envelope backpressure (`MaintenanceRequired`).
- Durable epoch barrier/mark/sweep with exact-parent reference protection,
  immutable mark evidence, resumable durable deletion progress, late-upload
  orphan reconciliation by actual listing, O(extant keys) cost.
- LocalHistory export/restore points: complete+fsync then atomic registry;
  owner-scoped cleanup; no remote epoch machinery.
- Independent verified-bytes backup (copy → read-back verify → manifest
  LAST, no-overwrite, operation-idempotent) and new-incarnation restore
  reaching the exact backed-up tip with empty executable receipts and
  preserved application bytes; read-only inspection grants no authority.
- Erasure via the Deleted authority preserving explicitly retained roots,
  with an honest residual inventory.
- `blank_initial_digests()` cross-check: **MISMATCH FOUND** — see defects.
