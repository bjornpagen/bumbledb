2. **Typed Rust templates + `params!` (was boundary 4).** `query!` now
   evaluates to a per-expansion TYPED TEMPLATE wrapping the owned immutable
   `::bumbledb::Query` — emission is self-contained (core paths only), so
   the ONE macro works re-exported from both `bumbledb` and
   `bumbledb-query`. `Deref<Target = Query>` keeps every untyped consumer

   column names (labels now retained on `HeadTerm::{Count, Agg}`) that used

   `bind(params! { name: value, … })`: a typestate builder closure —

   convert through a per-expansion `__BumbledbScalarArg` trait covering the
