## Implemented behavior (resume delta over the wave-A store)

- **One storage engine.** Every transitional module deleted (inventory
  above); `Db`/`WriteTx`/`InstanceBuilder`/`OwnedInstance`/`ReadInstance`/
  `WriterSession` and the sweeper all run on `storage/store`. The old
  on-disk format has neither writer nor reader in-tree; family recognition
  refuses old directories before touching them.
- **Write path:** closure over an in-memory net delta (set arithmetic;
  net-normalized against the parent — exactly the one-command final-set
  effect), serialized through the sealed `ChangeSet` boundary, judged as a
  complete final state by the production judge (C03), sealed with no host
  adjunct on the embedded path, one durable LMDB commit for facts +
  generation. Abort/panic/rejection never wrote a fact. Reentrancy is the
  typed `StoreError::ReentrantWriter` surfaced as `Error::Store`, not a
  deadlock. Poisoning: a failed apply after an applied prefix marks the
  transaction; later operations and commit refuse with the original error
  as the preserved cause.
- **Witness/conditional writes:** `Witness` reifies environment identity +
  generation with private fields (unforgeable); `write_from` convicts a
  stale witness as `ConditionalWrite::Moved { witnessed, current }` under
  the exclusive writer — an answer, not an error; foreign environments are
  `Error::ForeignWitness`.
- **Reads:** one owned coherent snapshot per `Db::read` lease; typed/dyn
  point reads by decoded projection equality; closed relations resolve
  against the sealed extension substrate; text borrows mapped pages.
- **Publication:** `InstanceBuilder::admit` runs the complete judgment;
  `Db::from_instance` re-judges through the store prepare path and adopts
  in one commit (a re-judgment rejection of an admitted instance is
  reported as corruption — the admission invariant, not a domain outcome).
- **Compaction:** `Db::compact` = one coherent source snapshot →
  `Store::adopt_snapshot` into a fresh store: rows, host records,
  attachment and generation from the one transaction (ENG-003 by
  construction); crash leaves dest absent/staged/complete.
- **Sweeper:** `Db::verify_store` re-derives every physical invariant with
  the engine's own key/fingerprint code and re-runs the production judge
  globally; typed findings, never a shortened report.
- **P14 seams:** forced-fingerprint constructors (`collision-probe`
  feature) at store construction only — production defaults untouched; the
  SPACE-01 census walk + page stats on the snapshot.
- Everything in the wave-A store section still holds: exact collision
  buckets, long-key-safe fixed-width keys, local u64 row surrogates
  allocated in the row transaction, elastic map under the exclusive gate,
  durable-only opens, family/layout refusals, judged multimap final state.
