## Implemented behavior (summary of the guarantees)

- Pure declarative intent; generation-time-only authoring evaluation; the
  runner consumes inert generated data; no runtime import of user migration
  functions, no code hash, no helper-purity framework, no coverage list.
- Inference only where one safe interpretation exists; ambiguous
  rename/drop/backfill/type/data changes refuse with the complete finite
  typed-requirement list and write NOTHING.
- Stable human labels (`NNNN-label`, ≤64 `[a-z0-9-]`) are never identity;
  all identity is native 32-byte digests recomputed from exact file bytes on
  every generate/check; a changed plan under a reused label is drift.
- Deterministic reviewable repo-local plans/history: same schema/intent →
  byte-identical files; native `render_plan`/`render_manifest` text written
  verbatim; manifest is the commit point (written last); interrupted
  leftovers are detected, reported by `check`, and deterministically
  removed/rewritten by `generate` (never recorded history).
- Complete source+target coverage and exactly-once destructive
  acknowledgements in every emitted plan; final `validate-schema` names the
  target schema.
- Bounded seed ingestion: caller-owned iterables read exactly once at
  generation, in event-loop-yielding chunks, through the core cell codec,
  charged against the caller's `ExecutionPolicy` (rows/inputBytes); hostile
  iterators are typed input failures with zero partial artifacts.
- Already-recorded (stale) intent refuses rather than being silently
  ignored (bounded decision: prevents typo'd intent from vanishing; the
  Drizzle-like flow deletes/updates consumed intent after recording).
- `generateMigrations`'s options spell chapter 33's `hints` as `intent`
  (illustrative-name decision, recorded).
