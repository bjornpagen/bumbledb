  taken owns an `Arc` to its ORIGINATING ledger and refunds once on drop —
  rebinding moves none of them; the scratch directory unlinks once by drop
  order (`DirCleanup` after env close) no matter how often the owner was
  rebound; the sealed result-byte charge keeps its origin (rebinding never
  re-prices — `byte_len` is invariant across rebinds). RAM backings read
  without consulting any ledger; rebinding one is a documented no-op.

## Implemented behavior (summary)

Chapter 12's five pieces on the successor store: (1) immutable validated
templates (validate → normalize → ground → DP → Free Join lowering,
unchanged); (2) snapshot-bound execution over `QuerySource` with the
lease's `WorkContext`; (3) preserved direct-probe + Free Join/COLT warm
paths over images rebuilt from canonical rows through one walker, with
exact interner text identity (Q-COLLISION: full-byte map, never a hash
verdict); (4) the complete cursor fallback for the supported language
(positive joins, filters, sets, point membership incl. dense guards,
negation, residuals, derived/rec sources), streaming into the shared
sinks; (5) one charged RAM→temporary-LMDB `ScratchRelation` backing
completed results AND every sink-internal state that can outgrow RAM:
projection/union/DNF seen-sets (`SpillSet`), aggregate group tables +
integer/exact-float accumulator banks + Pack claims (partition flushes,
merge-per-group — the accumulator merge laws in
`lean/Bumbledb/Float64/Sum.lean` license the partitioning; bits identical
to resident), and the rec seen/frontier state (the reach sink's ordered
`SpillSet`; Δ/acc/seal drains span both tiers by watermark). Q-DISK and
Q-BUDGET now hold for inputs, intermediate state and outputs; the RAM
tier below each allowance is the only unledgered growth (the allowance IS
its bound), and every scratch/slab byte is reserved before growth.
The one bounded restart composes with the spill: only a WORKING-byte
refusal from the resident attempt licenses the single fallback restart
(`is_working_exhaustion`); sink spill state charges SCRATCH bytes once
spilled, sticky sink errors surface at finalize without re-entering the
restart (the fallback shares the sinks, so a sink-state refusal would
reproduce), and the retry's own failure propagates — no loop by
construction (`forced_fallback` guard + reset-per-attempt).
Atomic answers: `execute` fills the caller's buffer only through
`finish_sink` after every rule/stage succeeded; `execute_complete` seals
`CompleteResult` only after full evaluation; failed work never becomes a
caller's logical result (Q-ATOMIC).

## Bounded decisions taken (chapter 61 authority order)

1. **DNF lowering retained under the existing MAX_RULES cap.** Chapter 12
   §7 allows existing flattening "when their estimated expansion fits";
   oversized Boolean structure refuses at validation (typed, never
   mid-normalization). The lazy bounded-branch enumeration for
   over-cap Boolean structure is recorded as an unfinished boundary, not
   silently claimed.
2. **Per-prepared-query image cache + interner.** The old shared per-Db
   cache died with the old Db; Db-level sharing needs a P02R/P00 seam
   (hub request below). Prepared reuse (the dominant warm pattern) keeps
   its amortization; correctness and identity checks are unchanged.
3. **Heap instances rebuild images per execution** (`ViewEpoch::Heap`
   tick): `OwnedInstance` has no durable identity to key a memo by;
   correctness must not ride on address comparison. Optimization seam
   (instance nonce) requested below.
4. **Untouched-relation image reuse across generations** degrades to
   rebuild-on-generation-change until P02R exposes per-relation change
   versions (request below). Same-generation reuse and pinned-snapshot
   query-local reuse are intact. (PERF-001 note: the old "append" path
   also copied the whole decoded prefix; this is not a new full-rebuild
   tax, but the per-relation version seam is the right fix.)
5. **Key-probe uniqueness reads are the reference row walk** (exact,
   image-free) until the store grows determinant probes — the same
   posture as P02R's `api/db/get.rs`. Recorded as the shared
   acceleration follow-up; the classifier and direct-probe lane are
   preserved so the fast path returns as a probe swap, not a redesign.
6. **Fallback text identity is intern-on-read** (charged); the
   hashed-word + exact-recheck text path for text-heavy strictly-beyond-
   RAM relations is a recorded boundary, not implied.
