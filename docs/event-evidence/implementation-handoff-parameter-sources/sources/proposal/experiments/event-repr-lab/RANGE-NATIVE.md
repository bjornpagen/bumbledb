# Native shared-exit admission and comparison

The [raw shared-exit screen](RANGES.md) is frozen. Its follow-up uses a separate
`range-native-src/` module tree and `.scratch/range-engine/` engine copy. The
original laboratory module tree, production files and previous native binary
remain unchanged. The [native comparison is complete](RANGE-NATIVE-MEASUREMENTS.md): correctness,
12 admission processes and 14 join processes pass. Grouping does not beat its
matched one-bit control on fresh Coup queries in this sweep.

## A complete scoped value

`RangeCarrier<0>` uses ordinary Shannon records and one-bit operations.
`RangeCarrier<1>` uses compressed selector records and one-bit operations.
`RangeCarrier<2>` uses the same compressed records with grouped operations.
All three have identical anchored support, import, transport, counting and
source-law adapters. Their semantics are the same support-relative Event value.
They use the established anchored convention: store a representative false at
a legal anchor, plus the Event's anchor-value bit. Boolean Apply adjusts its
truth table to preserve that invariant. Quantification and maps recover the
supported predicate and reseal the result.

This adapter uses explicit support masking and anchoring, like the existing
essential carrier. The raw Coup screen instead used completed predicates.
Native results must therefore compare the three matched scoped controls; raw
work counts cannot be carried into the native table as if only dispatch changed.
A completed-function wrapper remains a separate possible implementation.

Packet output expands selectors into ordinary ordered Shannon splits in the
existing shared interchange. Packet imports reconstruct exact named functions,
not probabilities. Local table import never expands a wide symbolic owner's
entire cube. Optional fused view products and direct relationship classification
are not advertised; ordinary relational composition and constructive occupancy
remain available through the existing interface.

## Shared parameters survive compression

A spectrum coefficient counts assignments by successes in each named parameter
group. Align the child spectra to their joint child coordinates. If `H` is the
high-child spectrum and `L` the low-child spectrum, the selector contribution is

```text
L + (product over selected v of (1 + z[group(v)]) - 1) * H
```

The implementation smooths `H` over the selected coordinates, subtracts its
all-zero-selector contribution, then adds `L`. Selector and child coordinates
are disjoint, but their parameter names may be identical. This preserves repeated
sampling with one unknown shared parameter. It does not replace the declared
joint law with independent marginals. The completed source contraction continues
to use the existing exact law evaluator.

The [shared adapter check](results/range-admission-fixed.json) passes for all
three modes. It includes the existing finite semantic/dependency/relational
suite, symbolic legal relations, symbolic diagonals, cross-carrier packets,
owner publication and compute-on-import, thirty exact coefficient-vector cases
per mode, forty repeated draws under a shared Beta parameter, and a
61-coordinate shared-parameter count. Coefficients are compared against all
worlds on eighteen-coordinate controls, including projection and complement.
The initial packet-builder method-name compile failure is retained with its
[failed source snapshot](results/range-admission-initial-src/manifest.json);
the [passing snapshot](results/range-admission-fixed-src/manifest.json) is separate.
The native harness subsequently changes its candidate dispatch and adds baseline
semantic checks; the admitted raw manager and scoped adapter are unchanged.

## Native sequence and completed scope

1. Build the separate engine with `range_native_build.py` and freeze its exact
   source and executable hashes.
2. Run `range_native_sweep.py --phase correctness` to check the same optimized
   native executable, including native dependency queries.
3. Run `--phase admission` for the three modes on owned computation, symbolic
   relations, transport and exact laws. These single-trial acceptance runs are
   not the performance ranking.
4. Run `--phase join` serially, with seven samples, both Coup presentations,
   triangle/clover joins and memo off/on. Include packed512, dense, essential512
   and retraction512 in the same executable. The existing query timer includes
   exact output counts; construction and oracle verification are separate.
5. The optional `--phase algebra` compares legal-world composition and information
   readouts in both orders. It was not run: the join sweep did not establish a
   benefit over the matched step control. Those wider performance cases remain
   unmeasured; algebraic acceptance has passed.

Never benchmark alongside compilation, another benchmark, Lean, or profiling.
Keep the three controls in one binary, preserve the matching input conditions,
and report each workload separately. No universal fastest representation follows
from one chain family or one Coup encoding.
