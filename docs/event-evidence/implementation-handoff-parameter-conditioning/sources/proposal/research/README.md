The seven `lineages/` documents and `papers/` remain research assets. Retained
source-process and polytope checks establish their stated finite examples, not
canonicality or throughput of the native event feature.

Revision 0.5 supersedes the representation round's automatic positive-mass
support convention. The older endpoint fixture remains a valid explicit
Supported(law) view. Active structural support is declared admissibility,
independent of whether a designated law assigns each world positive mass.
The early lineage recommendations and round-5 physical choices are research
history. The [revision 0.9 contract](../proposal.md) defines the implementation
baseline; the [proof matrix](../semantics/README.md) and
[laboratory report](../experiments/event-repr-lab/REPORT.md) delimit its evidence.
