## API (planned shapes; "Landed" below is authoritative)

Every export's TS type is in `ts/src/native/binding.d.ts` (generated by
`crates/bumbledb-node/dts.sh`, committed). Conventions:

- Outputs: plain objects; unions carry one discriminant `_tag` with PascalCase values.
- Counters and 64-bit integers: `bigint`, never `number`.
- Cold tree-shaped inputs cross as ONE JSON string. Unions use the discriminant `kind`
  (PascalCase variant names), fields are camelCase, unknown fields are refused, depth is limited
  to 128, and lone surrogates are refused. JSON value encoding: `u64`/`i64` as decimal strings,
  `f64` as the 16-hex-digit IEEE bit pattern (keeps -0, NaN and the infinities exact), bytes as
  lowercase hex.
- A malformed JSON input is the `_tag: "Malformed"` arm `{ path, message }` (a serde path like
  `rules[0].atoms[2].bindings`), never a generic `InvalidArgument`.
- The data plane (row cells, params, point-read keys, change records) stays JS-native values:
  `boolean | bigint | number | string | Uint8Array | { start, end }`.

Synchronous (D17, no executor):

```ts
compileSchema(specJson: string):
  | { _tag: "Compiled", schema: ExternalObject<SchemaHandle>, descriptor: SchemaDescriptorOut }
  | { _tag: "Invalid", diagnostic: SchemaDiagnostic }      // engine SchemaError, statement ids
  | { _tag: "Malformed", path: string, message: string }
validateQuery(schema: ExternalObject<SchemaHandle>, irJson: string):
  | { _tag: "Valid", query: ExternalObject<QueryHandle> }
  | { _tag: "Invalid", diagnostic: QueryDiagnostic }       // code + rule/atom/find/... indices
  | { _tag: "Malformed", path: string, message: string }
schemaBindings(schema: ExternalObject<SchemaHandle>):
  | { _tag: "Bindings", source: string }
  | { _tag: "Unrepresentable", coordinate: string, reason: string }
```

The schema file is the spec JSON itself (what `compileSchema` takes); there is no second
descriptor grammar and no `runtimeSchemaSnapshot`. Every verb that took a spec object now takes
the compiled `SchemaHandle` (db open/create, drafts, row codec). Query verbs take a `QueryHandle`.
